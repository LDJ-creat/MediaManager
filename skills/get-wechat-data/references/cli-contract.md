# CLI 契约（微信公众号数据）

编排入口：[media-manager](../../media-manager/SKILL.md)。

| 命令 | 说明 |
|------|------|
| `media wechat analytics fetch` | 抓取公众号分析数据 |
| `media wechat auth export` | 导出登录态 |
| `media wechat auth check` | 校验登录态 |

发布文章见 **post-to-wechat** skill：`media wechat post`、`media wechat check-env`。
