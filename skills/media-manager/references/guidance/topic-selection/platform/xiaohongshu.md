# 小红书选题指南

仅在选择小红书（`xhs` 内容族）时加载，与 `longform.md` 可叠加 `general.md`。

## 受众与形态

- 滑动阅读、收藏驱动；首图与前三行决定停留
- 笔记标题 ≤20 字；正文为短描述，主内容在信息图轮播

## 适合的选题

- 清单合集（「N 个 AI 工具」「3 步搞定 X」）
- 踩坑避坑、对比测评、入门科普卡片
- 个人实践小结（可视觉化）

## 选题与长文的关系

- **full-stack**：默认同题；长文深度展开，小红书做高密度提炼
- 仅当受众差异极大时，才允许小红书使用不同选题（需用户明确确认）

## 配图偏好（默认）

- 风格：`notion` 或 `study-notes`（技术向）
- 布局：`dense` / `list` / `flow`
- 可在本文件或复盘后更新用户偏好
