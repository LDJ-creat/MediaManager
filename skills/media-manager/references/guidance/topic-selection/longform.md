# 长文选题指南（微信 / CSDN / 掘金）

三平台共用一篇 `article.md`，选题偏好以本文件为准。

## 受众

- 开发者、AI 从业者、技术爱好者
- 期望获得原理理解、实践路径或可复用的工程经验

## 适合的长文选题

- 工具/框架深度解析、踩坑复盘、架构决策
- 有代码或流程可展示的技术教程
- 对热点事件的「工程视角」解读（非单纯转述）

## 不适合作为长文主选题

- 纯情绪种草、无技术信息增量的内容（留给小红书笔记形态）
- 需要大量图片展示、弱文字的信息卡片类（走 `xhs` 内容族）

## 标题方向

- 清晰传达主题与收益，可含技术关键词
- 具体平台标题变体在发布期由 `publishing/platform/*.md` 指导，不在选题阶段分叉
