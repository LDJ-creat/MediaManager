# 通用选题指南

适用于所有平台与内容形态。

## 选题原则

- 优先「可讲清楚、可验证、对读者有行动价值」的话题
- 避免纯新闻转述；需有明确写作角度或个人观察
- 同一周期内避免重复已写过的核心论点

## 评估维度

1. **时效性**：是否与近 48h 热点或读者当前痛点相关
2. **差异化**：能否提供不同于主流解读的角度
3. **可写性**：是否有足够素材支撑 1500 字以上（长文）或 5–8 张信息图（小红书）
4. **受众匹配**：是否符合技术/AI/编程自媒体定位

## 与 news-skill 协作

- 从 RSS 日报筛选时，标注每条候选的「一句话角度」和素材来源 URL
- 用户确认前不得锁定最终选题
